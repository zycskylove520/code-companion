## 七、进度真相源（通用模板）

真相源是进度的**唯一权威**，位于**第一节选定的学习目录**下的 `进度.md`（默认即 `<项目根>/.learning_memory/进度.md`；名冲突时是备选目录里的 `进度.md`）。至少包含：

```text
# <项目名> 源码精读进度
## 目标与边界地图
- 具体目标：（probe 收敛后的表述）
- strand 记录：每条线 → 地板 / 天花板 / 误解 / 从哪开始建（历史判定也留档，见下方不遗忘）
## 依赖地图（建课时确认的 mermaid graph TD；随教学演进，旧版留档）
## 周 / 天单元计划表
- W1 D1 → U001（主题、依赖前驱）；预计，不构成催促
## 当前状态
- 课程状态：学习中 / 已结课 / 流程结束待复核
- 当前单元指针：U<n>（结课后无下一单元）
- 当前卡 ID：C0001；任务版本：1；覆盖单元：[U001]
- 固定档案路径：card-archive/C0001.md
- 已完成 / 剩余：x / N；跳过未验证：单独列出，不计已掌握
## 待完成写入
- 无（更新中登记操作 ID、类型、旧卡/版本、目标卡/版本/档案、覆盖单元、目标状态及依据，按 engine/persistence.md 恢复）
## 已完成单元清单（只增不删）
- U001：完成于 YYYY-MM-DD，耗时 t_1
## 已会知识清单（持续累积，永不删除）
- YYYY-MM-DD · U<n>：具体会了什么（能讲清"为什么"，不是"看过"）
- 例：能独立讲清 vLLM 的调度器如何选 next token、为什么要分 prefill/decode
## 卡点与答疑记录（全部保留）
## 未完成项与回退
## 当前任务卡
（唯一活跃文件为 `当前任务卡.md`。正文格式见 `teaching/card-spec.md`；进度只保存其 ID、版本、覆盖单元和固定档案路径，不复制全文。首次发卡前建永久档案，答疑按知识点更新、重讲同步任务版本、完成核对补全。换卡、缺失恢复、状态冲突和结课一律按 `engine/persistence.md`，不跳过一致性检查直接重发。）
## 动态估算
- T_hat = N_remain × t_bar（t_bar 为最近 k 个单元平均耗时，需主人实测确认）
```

同目录还有：学习计划/总纲（依赖地图 + 周/天单元表 + 阶段验收与自测）、分卷计划（各单元条目 `- [ ]`）。**本 skill 只改学习目录与项目记忆，不改源码。**

### 7.1 不遗忘铁律（核心）

**学习记忆持续累积、永不遗忘**——因为带读的全部价值在于"始终准确知道主人学到哪、已经会了什么"。没有遗忘、没有归档清理、没有过期淘汰：

- **已完成单元清单、已会知识清单、卡点与答疑记录：只增不删。** 每条带日期与单元号，永久保留。
- **进度记录不设 archive、不做清理、不删旧记录。** 已会的知识即使很久没提也仍在；重新学习只是新增条目，不覆盖旧条目。永久知识档案的片段重组、重复措辞整合按 `engine/persistence.md` §2 执行（保留实质结论历史，不等于删知识）。
- **地图演进 = 追加新版本，不抹掉旧版。** 边界地图、依赖地图随教学修正时，把新版记为当前、旧版标注"截至 YYYY-MM-DD 的判定"另存（可在同文件用历史小节，或单独 `地图历史.md`），不静默覆盖。
- **改结论要留痕**：某条"已会"若后来发现其实没真懂，标注日期修正，旧判定保留并说明为何改——不直接删除。
- **续学必读全量已学记忆**：第三节续学时，`INDEX.md`/进度摘要可快速看当前位置，但**「已完成单元清单」「已会知识清单」「卡点与答疑记录」要完整读**，确保复述和下一步建立在主人真实已会的东西上，不遗漏、不重复教。

这里的"按需检索、INDEX 导航"只是**读取策略**（先读索引再按需深入），不是遗忘——文件一直都在、随时可读，绝不因为"很久没读"就删或归档。

**动态估算**：每完成一单元，按最近 `k` 个单元平均耗时 `t_bar` 重算 `T_hat`。`k < 5` 时只报「已完成 / 剩余 / 当前单元」，不给预计完成时间。估算写回真相源、标注"需主人实测确认"，**不构成排期压力**。
