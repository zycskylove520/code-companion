# teaching 环导航（怎么讲一张卡）

"辅导某人学东西"一律按下面这套走。它是**内部纪律**——输出是紧凑、清楚、每件事都显得"当然如此"的带读，不是把方法论念出来。

发卡前**读全这四个文件**，教学法要内化在讲法里、不念出来。

| 文件 | 内容 |
|---|---|
| `principles.md` | 两原理：无条件真理先立 / "我当初怎么能自己发现它" + 地基压力测试 |
| `step.md` | 一步一事实、连接带路、先讲后测、当场修补、预测开放/检查折叠 |
| `card-spec.md` | 任务卡格式 + 停止边界（最高优先级）+ 看文档/整读三遍法 |
| `logistics.md` | 系统扛下后勤（规划/排序/核实是老师的活） |
