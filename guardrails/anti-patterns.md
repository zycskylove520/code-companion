## 十、自检清单（每次收尾前过一遍）

**建课时：**
- [ ] 「开始学习」第一步扫描项目根下带 `.code-companion` 标记的 `.learning_memory*` 隐藏目录来定位（索引 `MEMORY.md` 随目录一并读，不在项目根留裸目录）？若多个带标记目录，有没有按协议取状态最新者并提示主人？若默认名不带标记（名冲突），有没有改用备选名、打标记、在目录内建索引、绝不写入别人的目录？
- [ ] 空目录时按"通读源码 → 摸边界 → 共同规划 → 划分周/天单元 → 落盘"走全了？
- [ ] probe 一次只问一个问题，每条 strand 都有地板/天花板，目标问具体了？
- [ ] 引导式问过时间周期、学习范围、顺序偏好了？
- [ ] 摸边界收束后已把结论写成学习目录内唯一的 `能力边界.md`（目标/编排信息/各 strand 边界/日期与来源齐全），读回核对后才进共同规划？
- [ ] 规划是最小树、地基压力测试过、依赖地图给主人确认过（本回合没开教）？

**每次带读：**
- [ ] 唯一 `当前任务卡.md` 按 card-spec 完整格式先落盘并读回核对、再展示且与文件逐字一致？换卡时原地更新这一张，结课时保留正文并标记终态，不新建活跃卡？
- [ ] 每张答疑后已立即写进该卡档案并**按知识点调整对应片段**（命中就补充/澄清/带痕修正，全新主题才新增），没有硬追加流水账？修正旧结论带痕保留旧说法与日期？
- [ ] 首次发卡前建立固定 ID 对应档案、保存全文，主题改名不改变档案路径，覆盖单元列表明确？完成仅核对补全，不重复建档？
- [ ] 续学读了当前未完成卡档案的知识片段与待解问题？核对进度/卡/档案 ID、版本和待完成写入后才重发？卡缺失优先从档案恢复，无法恢复时明确告知？
- [ ] 按 `engine/persistence.md` 登记待写→先档案→当前卡→提交进度，失败不推进；重试同一操作不重复记录？
- [ ] 重讲的新版本已先保存在同一档案，再同步当前卡？
- [ ] “继续/OK/看完了”没有被直接记为掌握，明确跳过标未验证，部分掌握只记证据覆盖部分？
- [ ] 最后一张完成后进入已结课/待复核，保留最后任务正文，不生成不存在的下一张？
- [ ] 每次只发一张卡，结尾两问都问了？
- [ ] 卡片带进度三数、地基/动机、有「停在这里」边界、代码是整读不是碎片？
- [ ] 一个推理步一测，先讲后测，没落地当场修补、不在未验证的步上推进？
- [ ] 所有行号都先用工具核实过？
- [ ] 答疑时先答后拉回边界，没有把下游讲完？
- [ ] 推进前先验证掌握并留证据？已会清单**只追加有证据的项**，带日期与"为什么"；“继续/OK/看完了”未被写成已掌握，明确跳过写入待复核？
- [ ] 续学时完整读了已完成清单/已会清单/卡点记录，复述建立在真实已会上（没有遗忘、没有重复教已会的）？
- [ ] 地图演进留历史、不静默覆盖？进度记录无 archive/过期淘汰；永久档案允许整合重写但保留实质判定历史，没有被清理或删掉旧知识？
- [ ] `能力边界.md` 随答疑/重讲/重夹逼/验证推进同步更新了对应 strand（地板随证据上下移、下移说明旧判定为何过高；误解与卡点在「边界移动轨迹」留痕、日期与证据齐全；已会/卡点流水未复制进本文件）？续学时读过它、缺失时按协议补建？
- [ ] 周/天只是视图，没有被当成日历催进度？
